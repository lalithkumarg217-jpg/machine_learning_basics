# Machine Learning Journey

A collection of machine learning projects built while learning Python, Data Science, and Machine Learning using Scikit-learn.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Projects

### 1. Salary Prediction
- Algorithm: Linear Regression
- Dataset: Salary_Data.csv
- Goal: Predict salary based on years of experience.

### 2. Startup Profit Prediction
- Algorithm: Multiple Linear Regression
- Dataset: 50_Startups.csv
- Goal: Predict startup profits using multiple features.

### 3. Mushroom Classification
- Algorithm: Logistic Regression
- Dataset: mushrooms.csv
- Goal: Classify mushrooms into different categories.

## Topics Covered

- Data Preprocessing
- Train-Test Split
- Linear Regression
- Multiple Linear Regression
- Logistic Regression
- Model Training
- Model Evaluation
