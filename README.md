# Machine Learning Basics

A collection of Machine Learning projects built while learning Python, Data Science, and Machine Learning using Scikit-learn. This repository contains hands-on implementations of various supervised learning algorithms using real-world datasets.

## 🚀 Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## 📚 Projects

### 1. Salary Prediction
- **Algorithm:** Linear Regression
- **Goal:** Predict salary based on years of experience.

### 2. Startup Profit Prediction
- **Algorithm:** Multiple Linear Regression
- **Goal:** Predict startup profits using multiple input features.

### 3. Mushroom Classification
- **Algorithm:** Logistic Regression
- **Goal:** Classify mushrooms into edible or poisonous categories.

### 4. Drug Classification
- **Algorithm:** Decision Tree
- **Goal:** Predict the appropriate drug based on patient attributes.

### 5. Drug Classification
- **Algorithm:** Random Forest
- **Goal:** Improve drug prediction accuracy using an ensemble learning method.

### 6. Iris Flower Classification
- **Algorithm:** Support Vector Machine (SVM)
- **Goal:** Classify Iris flowers into different species.
